# 엑셀 헬퍼 v1.4.0 — 웹사이트 배포 패키지

엑셀 헬퍼는 AI를 호출하지 않고, 저장된 도움말과 규칙 기반 자연어 검색으로 Excel 사용 방법을 안내하는 정적 웹사이트입니다.

## 기존 Cloudflare Pages에 업데이트하기

1. `Excel_Helper_v1.4.0_Website_Update.zip` 압축을 풉니다.
2. GitHub 저장소 `excel-helper` → `Add file` → `Upload files`로 들어갑니다.
3. **ZIP이 아니라 압축 안의 파일 8개**를 선택합니다. `index.html`, `data.js`, `search-core.js`, `app.js`, `example-visuals.js`, `styles.css`, `.nojekyll`, `README.md`가 저장소의 최상위(루트)에 있어야 합니다.
4. 기존 파일 변경 내용을 확인하고 `Commit changes`를 누릅니다.
5. Cloudflare Pages의 배포 현황이 성공인 것을 확인한 후 기존 주소 `https://excel-helper-76o.pages.dev/`에 접속합니다. 오래된 화면이면 Ctrl+F5를 누릅니다.
6. 상단에 `v1.4.0`이 표시되는지 확인하고 아래 검색어를 테스트합니다.

> 실제 GitHub / Cloudflare 계정에 대한 쓰기 권한이 없기 때문에 이 패키지는 **아직 공개 사이트에 적용되지 않았습니다.**

## 주요 개선

- `A1~A10 전부 더하기`, `A5와 B5 글자 띄어쓰기해서 합치기`의 의도 판별을 수정했습니다.
- 직원별/월별/시트별 합계, 예산 잔액, 한 페이지 인쇄, 빈 행 삭제, 셀 참조 고정, 문자열 나누기 등 검색 구분을 보강했습니다.
- 남성/여성 + 참여상태 + 이용횟수, 연도와 월 + 참여상태, 출생연도 + 참여상태 + 횟수 조합의 가상 표와 FILTER 수식을 지원합니다.
- SUMIF vs SUMIFS 비교 도움말을 추가했습니다.
- 예시 표 A·B·C·D 열과 1·2·3행 표시 및 예시 값/수식 간 불일치를 수정했습니다.
- 모바일에서 감춰졌던 `저장한 도움말` 기능을 다시 사용할 수 있도록 했습니다.
- 지원하지 않는 복합 조건은 일부를 누락한 수식으로 답하지 않고 제한 사항을 안내합니다.
- 모든 함수 411개는 이름 검색을 검사했으나 전체 함수의 독립적인 상세 설명이 있는 것은 아닙니다. 상세 설명이 있는 함수는 127개입니다.

## 주요 테스트 질문

- `A5와 B5를 띄어쓰기해서 하나로 만들어줘` → 글자 연결
- `A1~A10 값을 다 더하려면` → SUM(A1:A10)
- `남성 참석자 중 5회 이상 사람 찾기` → 성별/횟수/참여 FILTER
- `2025년 10월에 참여한 사람 찾기` → 날짜 범위/참여 FILTER
- `2005년생 중 3회 이하 미참여한 사람` → 출생연도/횟수/참여 FILTER
- `SUMIF랑 SUMIFS 차이` → 함수 비교
- `2005년생 남자 중 5회 이상 참여한 사람` → 미지원 다중 조건 안내

## 테스트 방법 (전체 소스 ZIP만 해당)

- 검색 규칙 자동 테스트: `node --test tests/*.test.js` (190건 통과)
- 브라우저 자동 시나리오: `python tests/browser_v140.py` (Chromium, 데스크톱 1440px / 모바일 390px)
- 브라우저 테스트는 외부 주소가 아니라 배포 ZIP과 같은 정적 소스를 DOM에 로드하여 테스트합니다. 외부 페이지 접속은 실행 환경에서 차단돼 실제 공개 도메인 접속·배포 검증은 실시하지 못했습니다.

## 한계와 개인정보

현재 사이트는 비AI 방식입니다. 등록되지 않은 질문을 자유롭게 추론하거나 실제 Excel .xlsx 파일을 읽고 수정하지 못합니다. CSV 로컬 미리보기 및 개인 도움말 기능은 현재 브라우저에서만 처리됩니다. 개인정보나 시설 비공개 자료는 질문창에 입력하지 않는 것을 권장합니다.
