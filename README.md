# 엑셀 헬퍼 v1.3.0

직원용 무료 엑셀 질문·답변 웹사이트. AI 서버 없이 HTML/CSS/JavaScript로 작동합니다.

## 실행

- 온라인: `https://excel-helper-76o.pages.dev/` (GitHub에 이번 버전을 배포한 뒤 적용됨)
- 오프라인: 배포용 ZIP을 압축 해제하고 `index.html`을 Chrome/Edge에서 실행

## 업데이트 (가장 중요)

1. 배포용 ZIP을 압축 해제합니다.
2. `https://github.com/pikadanny01/excel-helper` → `Add file` → `Upload files`를 엽니다.
3. ZIP **안의 파일만** 올리고 `Commit changes`를 누릅니다. ZIP 파일을 통째로 올리면 안 됩니다.
4. Cloudflare Pages에 설정된 자동 배포가 완료되면 기존 주소에서 `Ctrl+F5` 새로고침합니다.
5. 사이트 상단 `v1.3.0`이 보이는지 확인합니다.

## 테스트 질문

- `A열 이름이랑 B열 이름을 하나로 합치고 싶어` → 두 셀의 글자 합치기
- `A1과 B1을 더하고 싶어` → 두 셀 숫자 더하기
- `셀 두 개 합치는 법` → 셀 병합하기
- `A1이랑 B1 합쳐줘` → 뜻이 불명확하여 3가지 도움말 제시
- `2005년생 참석한 사람 수` → COUNTIFS 인원수
- `A열하고 B열 둘 다 있는 이름 찾아줘` → 두 명단의 공통 이름
- `VLOOKUP 함수 오류 #N/A` → 오류 진단

## 오해하기 쉬운 부분

- 사이트 주소에는 GitHub 사용자 이름이 보이지 않지만 **GitHub 저장소는 공개**되어 있습니다. 내부 자료·직원 개인정보는 등록하지 마세요.
- 개인 도움말 등록은 동일 브라우저에서만 사용할 수 있고, 모든 직원에게 자동 배포되지 않습니다.
- 모든 411개 함수의 상세 설명을 완성한 상태가 아니라 함수명 색인과 일부 개별 설명을 제공하는 형태입니다.
- 정확하지 않은 질문은 가능한 선택지를 제공하지만, 모든 실무 질문을 스스로 추론하는 AI는 아닙니다.
